VietQuill: Quality-Controlled Paraphrase Generation for Vietnamese

Sang Quang Nguyen, Kiet Van Nguyen
University of Information Technology, Vietnam National University, Ho Chi Minh City, Vietnam
GitHub Paper DOI

VietQuill is a quality-controlled Vietnamese paraphrase generation framework that enables explicit control over lexical overlap, syntactic similarity, and semantic preservation. The system employs a ViT5 model integrated with a specialized Quality Control (QC) evaluator for Vietnamese.
