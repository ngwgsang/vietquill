Overview

Why VietQuill?

VietQuill centralizes datasets, generation methods, augmentation techniques, and evaluation metrics into a consistent, unified interface.

Controllable Generation

Fine-grained control over lexical overlap, syntactic similarity, and semantic preservation levels to match your custom NLP downstream requirements.

Quality Estimation

Built-in neural quality estimators (vELECTRA) along with traditional metrics (BLEU, BERTScore, Jaccard, TED, ParaScore) to inspect paraphrases.

Optimized Architectures

Leverages strong Vietnamese pre-trained model baselines (ViT5-base) fine-tuned on clean large-scale sentence alignment benchmarks.

Quickstart Guide

Easily integrate VietQuill into your Python pipelines.

Terminal 
# Create and activate virtual environment
python -m venv .\venv
.\venv\Scripts\activate

# Install VietQuill package from PyPI
pip install vietquill
main.py 
from vietquill import AutoModelForControllableParaphraseGeneration

# Load default controllable paraphrase generator
model = AutoModelForControllableParaphraseGeneration()

# Paraphrase a single sentence
result = model.paraphrase("Hôm nay trời đẹp quá, mình muốn đi dạo công viên.")
print(result)
# >>> ['Hôm nay trời đẹp, tôi muốn đi dạo công viên.']

# Batch generate candidates with specific control levels
result_custom = model.paraphrase(
    "Tôi rất thích ăn phở vào buổi sáng.",
    lexical=90, syntactic=70, semantic=70,
    num_candidates=2
)
print(result_custom)
style_preset.py 
from vietquill import AutoModelForControllableParaphraseGeneration, ParaphraseStyle

model = AutoModelForControllableParaphraseGeneration()
sentence = "Mỗi ngày, có bao nhiêu người Việt Nam sử dụng mạng xã hội?"

# Generate with CONSERVATIVE style preset
c_res = model.paraphrase(sentence, style=ParaphraseStyle.CONSERVATIVE)
print(c_res)

# Generate with DIVERSE style preset
d_res = model.paraphrase(sentence, style="diverse")
print(d_res)
estimate.py 
from vietquill import AutoModelForParaphraseQualityEstimation

original = "Hôm nay trời đẹp quá, mình muốn đi dạo công viên."
paraphrase = "Thời tiết hôm nay thật tuyệt, tôi muốn tản bộ trong công viên."

# Load deep quality estimator model (vELECTRA base)
estimator = AutoModelForParaphraseQualityEstimation()
scores = estimator.estimate(original, paraphrase)

print(scores)
# >>> {'lexical_score': 24.48, 'syntactic_score': 78.26, 'semantic_score': 64.2}
eval_metrics.py 
from vietquill.evaluation import BLEUMetric, LexicalEstimator

original = "Hôm nay trời đẹp quá."
paraphrase = "Hôm nay trời đẹp ghê."

# Calculate BLEU score
bleu = BLEUMetric()
print(bleu.score(original, paraphrase))
# >>> 0.668740304976422

# Measure lexical alignment percentage
lex_est = LexicalEstimator()
print(lex_est.estimate(original, paraphrase))
# >>> {'lexical_score': 66.67}
